**Description:**  
A **complete library management system** for managing books, users, and borrowing/returning processes efficiently.  
**Key Features:**  
- Add, remove, and update books  
- Track borrowed and returned books  
- User authentication for admins and staff  
**Tech Stack:** Python, Flask, SQLite, HTML/CSS  
**Potential Improvements:** Add email notifications for overdue books and user dashboards.  
**GitHub:** [Library Management System](https://github.com/mrjawadd/LibraryManagementSystem)
